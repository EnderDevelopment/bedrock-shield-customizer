# BedrockShieldCustomizer

BedrockShieldCustomizer is a Minecraft plugin that allows players to customize the default shield with colors of their choice. This plugin provides a menu interface for players to personalize their shields, making it a unique and customizable item in the game. The plugin is designed for Minecraft Bedrock Edition servers and offers a range of color options to suit individual preferences.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft Bedrock server.
3. Restart the server to load the plugin.

## Use

1. Open the in-game menu by typing `/shieldcustomizer` in the chat.
2. Navigate through the menu to select the desired color for your shield.
3. Equip the shield to see the custom color applied.
